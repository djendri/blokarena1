BLOKARENA - si ta vendosesh në GitHub Pages
1. Krijo një repository të ri në GitHub (p.sh. blokarena), publik.
2. Add file > Upload files: ngarko TË GJITHA skedarët nga ky ZIP (jo vetë ZIP-in), pastaj Commit.
3. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
4. Pas 1-2 minutash merr lidhjen https://EMRI-JUAJ.github.io/blokarena/
5. Hape në PC (Chrome/Edge) dhe shtyp ikonën "Install" te shiriti i adresës.
   Android (Chrome): menuja > Install app / Add to Home screen.
   iPhone (Safari): Share > Add to Home Screen.
